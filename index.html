Estado de operación

Modelo del procesoG(s) = −0.8 / (120s + 1)
Constante de tiempo τ120 s

Proceso lento de inventario de pulpa. El signo menos vincula mayor abertura con menor nivel.

Acción del controlINVERSA

e = PV − SP; a mayor error positivo, más apertura de descarga.

Sintonía inicialZiegler–Nichols + ajuste

Punto de partida: Kp=2.0, Ki=0.020 s⁻¹, Kd=0. Comparar estabilidad, sobreimpulso y tiempo de asentamiento.

Es un modelo didáctico de primer orden. Los datos reales de planta deben identificarse antes de usarlo para operación industrial.

Lógica Ladder PLC (referencial)

RUNG 001  // Escalamiento de transmisor LT-101
 |----[ AI_LT101_mA ]----[ SCP 4..20 mA → 0..100 % ]----( PV_NIVEL )----|

RUNG 002  // Selección de modo
 |----[ MODO_AUTO ]-------------------------( PID_EN )-------------------|

RUNG 003  // Bloque PID, acción inversa
 |----[ PID_EN ]----[ PID  SP:=SP_NIVEL
 |                           PV:=PV_NIVEL
 |                           Kp:=Kp  Ki:=Ki  Kd:=Kd
 |                           Reverse:=TRUE ]----------------( CV_PID )---|

RUNG 004  // Manual / automático y límites
 |----[ MODO_AUTO ]------------------------[ MOV CV_PID → CV_VALV ]------|
 |----[/MODO_AUTO ]------------------------[ MOV HMI_VALV → CV_VALV ]----|
 |----[ LIM 0..100 % ]-------------------------( CV_VALV )--------------|

RUNG 005  // Salida analógica a LV-101
 |----[ CV_VALV ]----[ SCP 0..100 % → 4..20 mA ]----( AO_LV101_mA )------|
